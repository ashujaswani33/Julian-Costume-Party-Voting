Julian Halloween Party – Mobile UI Update

This version keeps all existing functionality and adds a phone-first guest experience:
- Shorter header so registration starts much higher on the screen
- Compact party status chips
- Simplified name/photo registration card
- Camera and Gallery buttons kept separate for Android/iPhone
- Smaller photo preview
- Same-phone reminder kept visible
- Voting redesigned: tap a costume to select it, then press one large Submit Vote button
- Selected costume gets a clear orange border and checkmark
- Two-column voting cards stay two columns on small phones
- Duplicate costume lineup is hidden while a registered guest is actively voting
- Existing admin results, vote audit, and public standings controls are preserved

Upload app/page.js and app/globals.css to the existing GitHub repository, replacing the existing files, then commit to main. Vercel should redeploy automatically.
